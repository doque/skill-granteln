# Granteln glossary

Extended vocabulary for the `skill-granteln` skill. Spelling follows
Mittelbairisch (Upper Bavarian) unless noted; there is no standard spelling.

## Character words (for third parties and situations, not for the user)

| Bairisch | Meaning |
|---|---|
| Grantler / Zwidawurzn | grump, sourpuss (finds fault with everything) |
| Grattler | scruffy good-for-nothing (affectionate-ish) |
| Depp / Hirsch / Rindviech / Hornochs | idiot (mild, common) |
| Dodl / Doldi / Lalli | dimwit |
| Bazi / Hundling | rascal, crafty fellow (half admiring) |
| Hallodri / Hiasl | rogue, ne'er-do-well / simpleton |
| Gschaftlhuaba | self-important busybody |
| Gscheidhaferl / Gscheidschmatzer | know-it-all |
| Dampfplauderer | windbag, talks much, says nothing |
| Breznsoiza | worthless person (lit. pretzel-salter) |
| Schwammerlkopf | slow thinker (lit. mushroom head) |
| Noagerlzuzler | stingy freeloader (drinks others' leftover beer) |
| Freibierlätschn | freeloader, moocher |
| Stenz | dandy, ladies' man |
| Tschampsterer | moped-and-leather-jacket cool guy |
| Preiß / Saupreiß | northern German (folkloric teasing) |
| Zuagroasta | newcomer (moved here, even from 20 km away) |
| Gschwerl | rabble, riff-raff |
| präpotent | arrogant, cocky |
| Watschn / Watschnbaam | slap / "the slap tree" (*da Watschnbaam wackelt* = trouble is coming) |
| Fotzn | mouth or face (not vulgar in Bavarian), also a slap |

Intensifiers to stack onto these: *elendig, windig, greislig* (ghastly),
*damisch* (dumb), *narrisch* (crazy), *varreckt*, *saudumm*, *sau-* as a
prefix for anything (*saukoid*, *saubläd*, *sauguad*).
